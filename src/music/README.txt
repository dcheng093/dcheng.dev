Drop .mp3 / .ogg / .m4a files in this folder and rebuild (or just save, under `npm run dev`).
Each one shows up in DANIELAMP after the built-in synth songs, sorted by filename, labelled from the filename:
  daniel-theme_v2.mp3  ->  "Daniel Theme V2"
Only add audio you have the rights to publish; the files are deployed with the site.
